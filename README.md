## The letter

**K** — standing for **"knackered"**.

## Why this letter

The day in one word: knackered. Not just tired — properly, gloriously
drained, the kind of tired where you flop onto the sofa still in your shoes
and the day replays itself behind your eyelids. It is vivid (you can see the
slumped shoulders), funny (it lands at once and is the sort of word you
repeat to a friend), and true to a real day — an honest report, not a
performance. And K fits it: a hard, punchy consonant for a hard, punchy
word, not the obvious E-for-exhausted pick.

## How it works

`main.ts` (Node 22, stdlib only) writes exactly one character — the letter
`K`, a single byte with no trailing newline — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).

## Run it

```sh
node main.ts
```

Then check the output:

```sh
wc -c /output/entry.txt   # 1
cat /output/entry.txt      # K
```
